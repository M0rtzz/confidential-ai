# 密文模型树结构报告

树结构报告从已核实训练回执中的 MODEL 密文对象生成。历史明文模型继续使用原计算入口；历史密文模型按原训练任务和回执定位，无需重新训练或重登记为 ASSET。

## 契约与授权

签名 TaskSpec 使用 `tee-contract/2.0`，仅支持 `report.tree_structure`、单个 MODEL 输入和单个 TREE_STRUCTURE 报告。API 外层、密钥信封、密文对象格式保留 `tee-contract/1.0`。签名参数固定 `inputKinds=[MODEL]`、`parserVersion=tree-report/1`，并绑定模型对象、原训练任务、策略摘要、特征及树索引。

每次请求、密钥释放、报告回执接收和报告读取都复核原训练策略及源密钥有效性、模型结果密钥绑定和贡献机构集合。任一原策略撤销或过期即拒绝；缓存不能延长授权。任务详情及可信链回执读取使用相同模型来源门禁。

V50 记录标准报告规则启用时间。启用后的决策树、XGBoost、LightGBM 训练自动获得随训练提供标准树报告的能力，训练完成后异步生成第 0 棵树。启用前的模型仅接受原策略已有报告授权，或 `ds_model_report_grant` 中针对具体模型和源策略的有效授权；部署不会批量放宽历史授权。

## 执行与返回

可信运行时解密模型，在临时内存目录内交给无身份凭据的低权限固定解析子进程。父进程与后端校验报告白名单。仅返回结构化节点、数值阈值、统计值和已授权特征，不返回模型二进制或训练样本。报告最多 800 个节点、UTF-8 JSON 内容最多 1 MiB；截断保留节点总数与分支标记。

缓存键包含模型对象、树索引、策略摘要和解析器版本。接口状态为 NOT_COMPUTED、RUNNING、AVAILABLE、FAILED、BLOCKED。FAILED 仅在明确重试时创建新任务，使用新 nonce；轮询沿用已有任务。报告失败不改变原训练状态。

TREE_STRUCTURE 属于允许明文持久化的受控 REPORT，存于已验签回执和报告缓存。模型与数据产物继续保持密文。仿真运行结果不代表硬件 TEE 或远程证明已通过。
